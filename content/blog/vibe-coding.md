# 随笔：Vibe Coding 之旅

最近，在网络冲浪中观察到 AI 发展之迅速。结合自己的一些想法，我买了 GPT Plus 会员，开始了新的一段 Vibe Coding 之旅。

过去曾经用 Gemini 和 GPT 做过一些小实验、小项目，但那时更像新手入门：花费时间和精力，慢慢摸索、探索。

## 从尝试到新的认知

现在我的认知有所不同，对使用 AI 也产生了一些新的见解。我会主动关注人工智能领域的新闻、不同模型的更新与迭代等等。

这段时间，我用 Codex 完成了 Tomatotodo 番茄待办这款 App 的开发，经历了多个版本的迭代，也维护了 GitHub 开源仓库，并申请了软件著作权，成就感满满。

我也逐渐了解到 MCP 的一些连接器功能。令人惊讶的是，AI 居然可以调用 Blender 实现自然语言建模，甚至可以操作 TouchDesigner、Godot、VCV Rack。沿着这个方向继续发展下去，未来的可能性让人有些不敢相信。

## 重新写一个个人网站

我浏览了不少程序员、设计师和设计团队的个人网站。那些网站的视觉冲击力和个人风格让我特别喜欢。

我之前也做过个人网站，使用了一些花里胡哨的组件库。以现在的目光回头审视，很多地方觉得又丑又俗，所以这次想从结构层面重新写我的个人网站。

这个过程比较花时间，应该是一个慢工出细活的过程。我做事“一口气通宵做完”的习惯，显然不适用于这种方法；每天投入的时间也应该被规划好。

如今过度依赖 AI，反而打破了实现效果时的技术问题。想法很多，就先暂时记下，再按计划执行，感觉也不错。

## 继续坚持艺术探索

对艺术的探索也要保持，并愈发深入。中央美术学院的考研计划也开始了。做网页开发的过程会变慢，更多精力要放在作品集的打磨上；读研前的练习和辅导也花费了不少钱，不能辜负自己和家人。

我要努力。日语也好，专业训练也好，都要坚持下去。坚持梦想吧！
